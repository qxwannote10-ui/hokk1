# 上海 — 城市介绍影片

一部可在浏览器里播放的上海城市介绍短片，约 1 分 13 秒。画面从片名开始，依次经过江海、尺度、两岸、高度、港口、街巷，停在“欢迎来到上海”。

## 播放

在项目目录启动一个本地服务器，然后打开页面：

```bash
python3 -m http.server 8765
```

浏览器访问 `http://127.0.0.1:8765`。

- 点击「播放」，或按空格键开始
- 空格键暂停 / 继续
- 左右方向键切换章节
- 底部进度条可以拖动

地址栏加上 `?autoplay=1` 会直接开播。

人口、轨道交通和港口数字来自上海市统计局《[2024 年上海市国民经济和社会发展统计公报](https://tjj.sh.gov.cn/tjgb/20250324/a7fe18c6d5c24d66bfca89c5bb4cdcfb.html)》。面积来自《上海概览》中 2023 年底的行政区划口径。上海中心大厦的 632 米来自[项目官方介绍](https://www.shanghaitower.com/ProjectIntroduction.html)。

北纬 31°14′、东经 121°28′ 是市区的约略位置。外滩与陆家嘴的天际线、长江口海岸都是示意图，没有按真实比例绘制。
